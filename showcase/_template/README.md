# Model submission form

Copy this folder into your event or community folder. Replace these instructions with your own factual report before submitting. This form is not a published model entry.

## What it does

Describe the user, the task and the output in plain language.

## Why we built it

Explain the real problem and why your approach fits it. If you fine-tuned, say why fine-tuning was needed.

## Dataset

State source, license, example count, review process and train/validation/evaluation split. Link public data when available.

## Training

State the tool, platform, exact base revision, method, hyperparameters, software versions, hardware and measured training duration.

## Run it locally

Provide complete commands that download the public artifact and run it. State the runtime, quantization, RAM or VRAM, context length and system prompt.

## Before and after

If you fine-tuned, show the same held-out prompt with real base and fine-tuned outputs. If not, show real test inputs and your app's outputs. Describe how you judged them. Include a failure or limitation.

## What we learned

Describe what helped, what failed and what remains uncertain.

## Team

List names and GitHub profiles. Credit data and tools you used.
